# Group Mini-Site (Arrays Only)

This project is a simple multi-page mini-site developed by **Group 4** for the course SENG412 as part of an academic assignment. The goal is to demonstrate the use of **HTML, CSS, and JavaScript arrays** to build interactive web pages without using any database.

---

## Pages

- **Home Page (`index.html`)**  
  Displays the list of group members with their matric numbers and the courses registered for the semester (course code and title).

- **Payroll Page (`payroll.html`)**  
  A simple payroll system for a small-sized company with **50 or more employees**. It calculates wages based on hours worked, hourly rate, and deductions, and displays both **gross pay** and **net pay** on a payslip.

- **GPA Page (`gpa.html`)**  
  Computes the **first semester GPA** of group members using predefined academic data stored in arrays.

- **Personal Details Page (`profile.html`)**  
  Displays personal details of group members including name, blood group, state of origin, phone number, and hobbies.

---

## Tech Stack

- HTML  
- CSS  
- JavaScript  
- Arrays only (no database, no backend)

---

## How to Run the Project

- Open `index.html` directly in any modern web browser  
**OR**
- Open the project folder in VS Code and click **Go Live** using Live Server
